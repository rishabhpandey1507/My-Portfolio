# Rishabh Pandey — Portfolio

This is a personalized version of the React portfolio template.

## Run locally
1. Install Node.js LTS from https://nodejs.org/
2. Open this folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run `npm install`.
5. Run `npm start` and open http://localhost:3000 if it does not open automatically.

## Update before publishing
- **Resume:** add your own PDF as `src/Assets/Rishabh_Pandey_Resume.pdf` and wire it into `src/components/Resume/ResumeNew.js`.
- **Projects:** update the `ghLink` values in `src/components/Projects/Projects.js` to each project's actual repository URL. Currently they point to your GitHub profile because exact repository URLs were not provided.
- **Contact:** add your preferred email/contact method when ready.
- **Profile links:** check GitHub and LinkedIn URLs in `Home.js`, `Footer.js`, and `Navbar.js`.
- **Skills:** edit `src/components/About/Techstack.js` to reflect skills you can confidently discuss in an interview.

Project descriptions are based on projects discussed previously; update their status/technology details if anything has changed.
